# Team Deathmatch Plugin for SCP: Secret Laboratory

A **fully customizable Team Deathmatch mode** for **SCP: Secret Laboratory** multiplayer servers.
Developed with the **Exiled API** and **Unity’s C# scripting system**, this plugin introduces fast-paced, team-based combat by assigning players to two teams, distributing loadouts, handling deaths, and declaring winners based on scores.

## Features

- **Automatic Team Balancing** — Players are evenly distributed between `Team1` and `Team2`.
- **Custom Roles** — Includes special classes such as *Chaos Rifleman* and *NTF Sergeant*.
- **Dynamic Spawn Points** — Players spawn randomly depending on their team and zone.
- **Match Logic** — Automatic game start and end conditions based on player count and score.
- **Announcer Event** — In-game audio and messages triggered by key match events
- **Score Display** — Displays team scores using in-game UI messages.
- **Automatic Restarts** — Instantly restarts rounds for continuous gameplay.
- **Commands** — Includes admin commands like `fst`, `Score`, `Self Respawn`.

### Description

This plugin transforms standard SCP:SL gameplay into an **intense, organized team deathmatch** mode.
It’s designed for community servers seeking a competitive and replayable game mode with built-in team balancing and scoring systems.
